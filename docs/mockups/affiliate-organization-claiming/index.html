Product decision

How a profile dispute is created

Proposed for implementation
1

Enter from context

“Report an ownership issue” appears on a claimed profile, an exact claimed match in organization creation, and an expired or denied transfer request.

2

Name the issue and desired outcome

The requester chooses former administrator, unavailable owner, unauthorized claim, duplicate profile, or other—then asks for transfer, correction, or claim review.

3

Prove affiliation or control

Use work email, DNS, HTML, or manual evidence. Domain proof strengthens the case but never silently replaces the existing owner.

4

Notify and review fairly

The current owner gets a bounded response window. Administrators compare independent evidence and may request information before calling the dispute credible.

5

Change public trust only when credible

Filing alone changes nothing. A credible dispute shows “Ownership under review” and removes the ranking boost while the existing owner keeps access unless separately suspended.

6

Resolve with an audited action

Uphold the current owner, initiate MFA transfer, revoke to unclaimed, suspend for credible fraud, or merge/correct a duplicate. Both parties receive the outcome.
